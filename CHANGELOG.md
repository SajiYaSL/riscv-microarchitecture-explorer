# Changelog

## 2.0.0 — 17 November 2026

- Rebuilt the workspace with fixed playback controls, visualization tabs, a synchronized inspector, a configuration drawer, and labeled mobile navigation.
- Added Guided/Expert experiences, bundled typography, three saved themes, a welcome flow, and a five-step tour.
- Added bookmarkable hash routes, guarded local persistence, compressed share links, saved experiments/presets, and pinned-run comparisons.
- Added 13 interactive lessons, quizzes, saved progress, a searchable glossary, and an assembly reference.
- Added command search, keyboard shortcuts, trace filtering/sorting, CSV/JSON exports, standalone SVG/PNG exports, and run-summary copying.
- Rebuilt processor diagrams and timeline navigation; added chart data tables and accessible keyboard/focus behavior.
- Added 38 browser tests, eight visual baselines, axe scans, and production bundle checks. All 91 unit tests pass, including the original 79 engine tests.
- Added refreshed icons, social artwork, documentation, and GitHub Actions browser coverage.

The assembler, CPU engines, simulation rules, and original `main` branch are unchanged. The redesign lives on `redesign/ui-v2`; individual phase commits are available in its history.
